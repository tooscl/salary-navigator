# Где искать навык и какие модели запускать

Один репозиторий содержит общий сборщик и две точки обнаружения. Не копируйте
runner/extractor в каталоги навыков и не загружайте один SKILL.md поверх старого
checkout. Версия инструкции, код и файлы данных должны относиться к одному commit.

| Исполнитель | Инструкция при открытии проекта | Навык | Модели этапов |
|---|---|---|---|
| Codex | `AGENTS.md` | `.agents/skills/collect-avito/SKILL.md`, вызов `$collect-avito` | `gpt-6-luna`, low → `gpt-6.1-terra`, medium |
| Claude Code | `CLAUDE.md`, который направляет в `AGENTS.md` | `.claude/skills/collect-avito/SKILL.md`, вызов `/collect-avito` | `avito-capture`, Haiku → `avito-review`, Sonnet |

После скачивания откройте **корень проекта** в выбранном приложении. Новую
сессию Claude Code откройте из этого каталога, чтобы обнаружились `.claude/skills`
и `.claude/agents`. Если каталог агентов добавлен в уже запущенную сессию и роли
не видны, перезапустите Claude Code. Пользовательское определение с тем же именем
или настройки организации могут изменить доступность/модель: проверьте фактический
запуск. Не изменяйте настройки организации, чтобы обойти ограничение.

## Подготовка до агентов

Preflight окружения выполняет ведущий до запуска любых агентов сбора/проверки
по одноимённому разделу общего skill. Первый запуск: настройка и сохранение
локальных путей. Следующие: повторное использование и короткий текущий probe.
В задание этапу входят готовый checkout, путь конфига, профиль и итог проверки;
повторная установка/импорт по одному отсутствующему файлу в новом checkout не нужны.

## Codex

Ведущий запускает отдельного агента через `collaboration.spawn_agent`:

- Браузерный этап: `fork_turns="none"`, `model="gpt-6-luna"`, `reasoning_effort="low"`.
- Проверка/исключения: `fork_turns="none"`, `model="gpt-6.1-terra"`, `reasoning_effort="medium"`.

Один Luna исполняет весь сбор последовательными вызовами capture по пакетам.
Terra подключается один раз после всех пакетов для finalize, проверки сводки
и публикации; во время сбора — только для разбора зафиксированной ошибки.
Успешный пакет не вызывает модельную проверку. После ремонта Luna продолжает
с checkpoint; общий журнал и бюджет сохраняются.

Модели и поля инструмента относятся к Codex. `agents/openai.yaml` — только
отображение/пример запроса, он не запускает эти модели и не выбирает модель
текущего чата. Ведущий может координировать процесс, но не заменяет оба этапа
своей моделью молча. Если инструмент или модель недоступны, сообщите ограничение
и согласуйте замену; не записывайте желаемую модель как реально исполнявшую этап.

## Claude Code

В проекте поставляются native-определения:

- `.claude/agents/avito-capture.md`: `name: avito-capture`, `model: haiku`.
- `.claude/agents/avito-review.md`: `name: avito-review`, `model: sonnet`.

Ведущий Claude использует свой инструмент делегирования (Agent/субагенты текущей
версии Claude Code), явно выбирает проектный `avito-capture`, ждёт завершения,
затем один раз после всех технических пакетов передаёт артефакты `avito-review`
для финализации и публикации. Промежуточный вызов разрешён только при ошибке,
требующей разбора; успешные пакеты не передаются проверяющему. Не вызывайте Codex collaboration API
и не передавайте GPT model ID в Claude `model`. В этих файлах нет обхода
разрешений: права наследуются от Claude Code и проекта.

`haiku` и `sonnet` — поддерживаемые Claude Code алиасы, а не закреплённые версии
моделей. Конкретный ID зависит от версии клиента, провайдера и доступных моделей
аккаунта. Не добавляйте GPT `reasoning_effort=low` к Claude. Настройки thinking/
effort и переопределения моделей проверьте в текущем клиенте; эти два маршрута
не являются измеренным сравнением качества GPT и Claude.

Смотрите модель фактически запущенного агента в доступных runtime-сведениях/
журнале клиента. Если известен только alias, используйте alias в метаданных
runner и явно укажите это в сводке. Не угадывайте полный `claude-…` ID. При
подмене моделью аккаунта сообщите об этом ведущему; замену маршрута согласуйте.

Короткое задание роли содержит: абсолютный путь checkout, путь общего SKILL.md,
run_id, точные фильтры/лимит, этап, путь конфигурации и разрешение/запрет публикации.
Проверяющему дополнительно передаются пути к raw и checkpoint, а не история чата.
Оба этапа читают общий навык из этого checkout, не делают fetch между собой,
не запускают себя повторно и используют общий бюджет failures.json.

## Метаданные запуска

Команды общие для обоих приложений. `--agent-model` у freeze и `--review-model`
у finalize **записывают** исполнителя, не переключают его:

| Исполнитель | freeze | finalize |
|---|---|---|
| Codex | `--agent-model gpt-6-luna` | `--review-model gpt-6.1-terra` |
| Claude Code, если известен только alias | `--agent-model haiku` | `--review-model sonnet` |

Когда полный фактический Claude ID доступен, передавайте его вместо alias.
В итоговой сводке укажите приложение, реальную модель либо alias с оговоркой,
ID/имена запущенных агентов, версию инструкции и commit. Не оставляйте
`gpt-6-luna`/Terra в командах, перенесённых в Claude из примера Codex.

## Скачать или перенести

Предпочтительный вариант для команды — скачать весь репозиторий/clone и открыть
его корень: точки обнаружения уже включены. Установка collect-avito глобально
не требуется. Если личный навык уже существует, укажите выбранный checkout
явно, чтобы не использовать устаревшую реализацию с тем же именем.

Для личной установки Claude использует `~/.claude/skills/`, Codex — каталог
навыков своего клиента. Копировать туда только нашу короткую точку входа без
репозитория бесполезно: относительные ссылки потеряются. Вместо этого держите
полный checkout и передавайте агенту его канонический SKILL.md по абсолютному
пути. Конфиги Happ, авторизация и cookies не переносятся вместе с навыком.

Форматы Claude проверены по [Skills](https://code.claude.com/docs/en/skills) и
[Subagents](https://code.claude.com/docs/en/sub-agents), 27.10.2026. Наличие файлов
и разбор frontmatter не заменяют проверку реального сбора в конкретной среде.
