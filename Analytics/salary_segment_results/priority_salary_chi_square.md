## Как применён χ²

Нулевая гипотеза — независимость значения поля и зарплатного исхода внутри `профессия × город`. Проверены два исхода. Первый — точная сумма или середина закрытой вилки против объявления только с границей. Второй — точечная зарплата выше медианы своей ячейки против остальных точек (включая равные медиане). Порог медианы рассчитан по поисковой части и заморожен для проверки. Бинаризация фиксирует направление относительно медианы и может пропускать различия формы распределения. Тест проверяет связь категорий. Величины в рублях и условия допуска оцениваются в исходных разрезах из неокруглённых зарплат.

Статистика — сумма χ² Пирсона по таблицам сопряжённости отдельных ячеек. P-значение получено 49 999 симуляциями таблиц с теми же маргинальными частотами в каждой ячейке; это учитывает малые ожидаемые частоты. В анализ включались категории с минимум пятью наблюдениями. Редкие значения объединены, если вместе набрали пять. Таблица с одной категорией или менее пяти наблюдений в одном исходе пропускается. Отсутствующее поле исключено из теста по этому полю. Для мультивыбора «нет» означает заполненное поле без указанной опции. V = √(χ²/n) для бинарного исхода, сводная величина связи по стратифицированным таблицам; на малых таблицах она может быть завышена.

Работодатели распределены по стабильному хешу наблюдаемого нормализованного имени. Поисковая часть — 1401 вакансий от 452 работодателей; проверочная — 624 от 205. 9 вакансий без известного работодателя исключены из χ² и учтены в описании полного снимка. Для каждого исхода из каждого работодателя выбрана одна вакансия с фиксированным seed. Это снижает влияние повторных объявлений. Разные варианты названия одного бренда всё ещё могут попадать по разные стороны. Холм при α = 0,05 применён ко всем выполненным поисковым тестам, а для проверки — к найденным заранее комбинациям поля и исхода. По группам отдельно переоценён интервал медианы, пересэмплируя названных работодателей целиком.
