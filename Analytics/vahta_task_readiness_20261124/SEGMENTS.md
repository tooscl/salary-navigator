Общий пул включает три дочерних среза и ещё 54 объявления смежных складских ролей. Строки таблицы не суммируются. Названия ролей — фильтры, не ручное подтверждение обязанностей. Это аналитические срезы для следующего этапа проверки, не вывод о готовности моделей.

Допущения отбора: явно net, заявленная сменная единица, диапазон 1 000–15 000 рублей, ширина закрытой вилки не более 50%; исключены обнаруженные противоречия, множественные ставки, сдельный контекст и военные признаки. Для дочерних срезов требуется одна складская роль по ключевым словам. Период карточки принимается, если правило не нашло противоречий в описании. Отсутствующие часы и объект сохраняются неизвестными. Нижняя граница не заменяет точную сумму.

Из 453 у 180 есть текстовая связь суммы/периода; у 273 остаётся допущение по карточке. Среди 194 закрытых сумм текстовая связь есть у 67, это 37 групп источников. Явно оплачиваемые часы есть только у 3, текстовый объект у 50, отдых не распознан ни у одного. Поэтому нельзя объявлять весь пул сопоставимым по почасовой нагрузке, объекту или полному циклу. Группы источников не являются подтверждённо независимыми работодателями.

ID и основания отбора: inputs/warehouse_selected453.csv; показатели условий: results/prepared_segments4.csv; полные цитаты по ID: results/vacancy_conditions7193.csv.
