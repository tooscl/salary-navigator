# Удалённые вакансии: прогноз опубликованных ставок

[Ноутбук](remote_model.ipynb) · [PDF-отчёт](output/pdf/remote_model_report.pdf)

Эксперимент на снимке из 32 097 объявлений. Удалённый формат указан у 4 147 вакансий: 3 334 только удалённые и 813 с несколькими форматами. В широком прогоне 3 384 числовые цели. В строгом 306 ставок с подтверждённым периодом: 107 за месяц, 111 за смену, 48 за час, 27 за действие и 13 за неделю.

## Итог

| Единица на строгом тесте | N | MAPE базы | MAPE калиброванного CatBoost | Покрытие CatBoost |
|---|---:|---:|---:|---:|
| Месяц | 107 | 76,1% | 62,6% | 49,5% |
| Смена | 111 | 53,2% | 49,9% | 57,7% |
| Час | 48 | 65,2% | 113,5% | 45,8% |

На месяце отдельный Ridge + TF-IDF дал 59,7% MAPE и 46,7% покрытия. Общий CatBoost с правилами и TF-IDF без калибровки дал 55,9% MAPE, но покрыл только 26,2% ставок. Для смены отдельный CatBoost без калибровки дал 43,8% MAPE при 21,6% покрытия; с калибровкой — 48,3% и 62,2%. Слабые месячные кандидаты ухудшили MAPE до 64,7% относительно калиброванного варианта, но сравнение меняет и режим калибровки; относительно тех же правил без калибровки MAPE снизился с 67,5% до 64,7%.

Этого недостаточно для автоматической оценки. Проверяйте период и сравнимость ставки, показывайте показатели по единицам и сохраняйте эмпирическую базу. Варианты подбирались на текущем снимке, внешний тест ещё не проводился.

## Методика

- Для точной ставки берём её значение, для закрытой вилки — середину. «От» и «до» обучаются как опубликованные границы. Период, форма и налоговая база — отдельные входы при прогнозе. Пересчёта в условный месяц и пересчёта налогов нет.
- Для неизвестного периода из карточки ищем совпадающую точную сумму, границу или полную вилку рядом с явной единицей в описании. Формулировки частоты выплат не считаются периодом ставки. Вознаграждения, явно описанные как премия, не используются для восстановления основной ставки. В строгую выборку входят только явные ставки карточки или совпадения из описания с разумными границами. Исключены флаги военных, партнёрских карточек, платного входа и конфликта налоговой базы.
- Отдельно проверяем, помогает ли добавить кандидаты на месячную оплату, у которых в описании есть денежный контекст и месяц, но нет подтверждения той же суммы. В каждом фолде такие кандидаты добавляются только в обучение. Метрики считаются на строгом тесте.
- Пять внешних фолдов по группам источников. Группы связывают нормализованное имя, профиль, совпадающее описание, общий длинный префикс описания и повторяющийся шаблон заголовка и нижней суммы у трёх и более источников. Учитывается алиас Voxys. Группа — приближение к зависимости объявлений.
- Карточка и роль из заголовка, 103 признака M4 и правила удалёнки. Для текста применяем удаление сумм; для TF-IDF дополнительно удаляем оставшиеся цифры и ссылки. Название работодателя, ID и сумма ставки не передаются модели.
- Сравниваем эмпирические квантили, несколько CatBoost, символьный и словный TF-IDF, Ridge, ансамбль и отдельные модели по единицам. Калибровка использует четверть групп обучающей части каждого фолда. Базовый вариант опирается на квантили по единице, форме, налоговой базе и роли с переходом к более крупным группам.

Предыдущий ноутбук по удалёнке использовался для правил ролей и условий. Таблица разметки операторов содержит 780 ID, из которых 3 совпадают с этим снимком. Она послужила источником правил и проверкой состава выборки, её строки не добавлялись как новые обучающие данные. Точные ссылки на исходные файлы и ревизию в [provenance.json](provenance.json).

## Запуск

Из корня проекта с материализованным Data/dataset/vacancies.csv и Python 3.12:

    python -m pip install -r ML/experiments/2026-11-26_remote_model/requirements.txt
    python -X utf8 ML/experiments/2026-11-26_remote_model/remote_data.py
    python -X utf8 ML/experiments/2026-11-26_remote_model/remote_train.py
    python -X utf8 ML/experiments/2026-11-26_remote_model/remote_specialists.py
    python -X utf8 ML/experiments/2026-11-26_remote_model/remote_predict.py vac.csv prediction.csv --unit month --tax net --quote-kind central

Ноутбук показывает результаты без повторного обучения. Параметр RUN_TRAINING запускает новый прогон в ML/.cache/remote_runs. Прогноз требует явного запрашиваемого периода. Число references показывает объём строгих примеров с тем же контекстом, low_support помечает контексты с менее чем 20 карточками. В качестве сравнения доступны эмпирическая база и калиброванный специалист за смену или месяц.

В results/ хранятся результаты проверки, прогнозы по фолдам, схема, веса и важность признаков. Сырой текст, локальные окружения и кеш признаков в Git не сохраняются.
