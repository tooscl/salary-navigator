## Проверка

Пять фолдов по связанным работодателям, профилям или точным дублям
нормализованного описания. Векторизаторы и сокращение размерности обучаются
внутри обучающей части. Модели суммы получают единицу, налоговую базу и
форму как условия запроса. Их метрики предполагают, что эти условия уже
известны. Отдельный классификатор угадывает формат объявления по тексту
и карточке, но результат классификации не используется для подмены единиц.

В полном прогоне сравниваются эмпирические квантили по типу ставки и
профессии, CatBoost по карточке, CatBoost с правилами Кости, вахтовыми
дополнениями и признаками M4, дополнительный NLP, символьный TF-IDF,
символьный и словный TF-IDF вместе, Ridge, специализация по единицам и
ансамбль CatBoost/Ridge. Кроме того, для фиксированного диапазона сменных
ставок есть отдельный прогон и калибровка на группах из обучающей части.

Из 1 686 ставок с единицей «смена» у 209 хотя бы одна граница выше
50 000 ₽. Это сигнал проверки единицы, а не доказательство ошибки.
Отдельный сменный эксперимент исключает такие записи и ставки ниже 300 ₽,
полный их сохраняет. Явно оплачиваемые часы найдены у 7 сменных карточек,
точная сумма за полный цикл и явное число смен — у 6 карточек.
Этого недостаточно для самостоятельного обучения на пересчитанных ставках.

| Вариант | Вакансий | MAPE | Покрытие | MAE |
|---|---:|---:|---:|---:|
| Эмпирические квантили | 1 477 | 25,1% | 49,8% | 1 701 ₽ |

MAPE калиброванной модели ниже базы на 2,8 п.п. (95% интервал
−4,5…−1,3 п.п., парный бутстрэп по группам). Покрытие отличается по
форме предложения: 52,5% для точной ставки и вилки (711 вакансий),
47,1% для «от X» (620), 38,4% для «до X» (146).

### Общая модель на ставках с известной единицей

CatBoost с правилами обучен на 1 695 ставках в заранее заданных диапазонах
для каждой единицы. Границы одинаковы для всех фолдов. Для часа и суток
набралось три примера на две единицы, поэтому их метрики приведены только
в полном прогоне, где видно ограничение размера выборки.

| Срез | Вакансий | MAPE базы | MAPE CatBoost | Покрытие CatBoost |
|---|---:|---:|---:|---:|
| Смена | 1 477 | 25,1% | **21,5%** | **50,7%** |
| Месяц | 146 | 30,5% | **23,2%** | 37,7% |
| Цикл вахты | 69 | 34,4% | **23,1%** | 43,5% |
| Три единицы вместе | 1 692 | 25,9% | **21,7%** | **49,3%** |

Для полного цикла в широком сравнении вариант карточка + символьный
TF-IDF дал 21,9% MAPE и 50,7% покрытия. Это результат на 69 объявлениях,
отдельной проверки на свежих данных не было.

### Буквальный прогон и классификатор формата

На всех 7 269 числовых целях специалисты по единицам дали лучший
pinball loss (0,1679). CatBoost с правилами дал медианную абсолютную
процентную ошибку 16,9% и покрытие 47,8%. Общий MAPE малоинформативен:
одна фраза «выплата ЗП 2 р в мес» из карточки без суммы была распознана
как 2 ₽/мес и дала примерно 89% суммы процентных ошибок у этой модели.
Сохранили этот пример в буквальном прогоне. Прогон с известными
единицами отбрасывает его по заранее определённой нижней границе.
Медианная ошибка суммы без периода — 15,5% у CatBoost с правилами,
покрытие 49,5%. Это оценка числа в объявлении.

Классификатор формата получил accuracy 72,8% и macro-F1 33,3% на всех
7 310 карточках. База «всегда период неизвестен» даёт accuracy 72,8% и
macro-F1 14,1%. Классификатор не использовали для восстановления
неизвестных единиц в зарплатной модели.

## Воспроизведение

С Python 3.12, зависимостями из `requirements.txt` и материализованным
датасетом, из корня репозитория:

```powershell
$exp = 'ML/experiments/2026-11-25_vahta_model'
python -X utf8 "$exp/full_data.py" --out ML/.cache/vahta-full-cache
python -X utf8 "$exp/full_train.py" --cache ML/.cache/vahta-full-cache
python -X utf8 "$exp/full_shift.py" --cache ML/.cache/vahta-full-cache
python -X utf8 "$exp/full_shift.py" --cache ML/.cache/vahta-full-cache --known-units
python -X utf8 "$exp/full_predict.py" vac.csv pred.csv --variant known_plausible_calibrated --unit shift --tax net --quote-kind central
```

Результаты и веса сохраняются в `full_results/`. Контекст прогнозируемой
ставки можно передать в CSV по строкам колонками `unit`, `tax` и
`quote_kind`. `reference_offers` показывает число примеров с таким
контекстом в обучающем срезе. Для отсутствующего в обучении контекста
числовой прогноз пропускается.
