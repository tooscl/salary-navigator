# Вахта: прогноз опубликованной ставки за смену

Отдельный [широкий эксперимент](FULL.md) использует все 7 310 карточек
и оценивает опубликованные ставки по нескольким единицам и формам оплаты.

Эксперимент на снимке из 32 097 вакансий (ревизия `f599192d2`, SHA-256
`a56e81b2b7f524da57ca93ce4c6fe984dae950d67ec98b9f37429e5fde76983e`).
Из 7 310 вакансий с полем «График = Вахта» после исключения военных осталось
7 176. Подошли 612 ставок с определённым периодом и налоговой базой, из них
590 за смену на руки. Два отдельных таргета: опубликованная точная ставка
или середина закрытой вилки (300 вакансий) и опубликованный минимум «от X»
(290 вакансий). Для месяца, часа и полного цикла мало наблюдений.

Таргет строится из карточки и кандидатов из описания. Исключаются
неопределённая налоговая база или период, конфликт карточки и текста,
несколько основных ставок, сдельный контекст, совпадение сменной суммы с
суммой за несколько смен и значения за пределами заданных границ. Границы
для смены — 300–50 000 рублей. Молчание описания о ставке не отменяет
явную ставку карточки, поэтому это эксперимент по опубликованным
предложениям. Оплачиваемые часы используются как признак при наличии.
Месячные эквиваленты через 176 часов и фактические выплаты не оцениваются.

Карточка, условия из очищенного текста, правила Кости
`rules-context-1.0`, дополнения `vahta-additions-1.1` и три NLP-признака
сравниваются с историческими квантилями по профессии и друг с другом.
Исходники правил и их тесты взяты из коммита `34cff91b3`.
В признаки не передаются суммы, цитаты, название работодателя или полный
текст адреса. Регион карточки — регион размещения, а не подтверждённое место
работы. При кросс-валидации связанные по названию работодателя, профилю или
одинаковому очищенному описанию объявления объединяются транзитивно и
остаются в одном фолде. Это прокси для связи источников, не проверка юрлиц.

## Результаты

Пять фолдов по группам источников. Покрытие — доля опубликованных ставок
в прогнозном коридоре с целью 50%.

| Срез | Вариант | Медианная ошибка | MAPE | Покрытие | Pinball loss (log) |
|---|---|---:|---:|---:|---:|
| Точная ставка / вилка, 300 | Медиана по профессии | 12,0% | **20,5%** | **48,3%** | 0,0942 |
| Точная ставка / вилка, 300 | CatBoost по карточке | 13,6% | 20,7% | 32,7% | 0,0933 |
| Точная ставка / вилка, 300 | CatBoost по карточке с калибровкой | 14,9% | 22,1% | 43,3% | 0,0990 |
| Ставка «от X», 290 | Медиана по профессии | 22,2% | 28,5% | 47,9% | 0,1515 |
| Ставка «от X», 290 | CatBoost + правила Кости, вахты и M4 | 16,2% | **25,6%** | 22,8% | 0,1101 |
| Ставка «от X», 290 | Та же схема признаков с калибровкой | 19,2% | 27,9% | **50,7%** | 0,1268 |

Для точной ставки или вилки лучше оставить простую базу: добавление
признаков Кости, M4 и NLP не дало выигрыша. Для ставки «от X» можно
тестировать калиброванный CatBoost. До калибровки модель с правилами
показала MAPE на 2,9 п.п. ниже базы, но парный бутстрэп по источникам
дал 95% интервал от −9,1 до +4,0 п.п. Устойчивое улучшение MAPE
на этих данных не подтверждено. Добавление трёх NLP-признаков
не улучшило pinball loss ни в одном срезе.

Калибровка делит обучающую часть каждого внешнего фолда по источникам
на 75% групп для CatBoost и 25% для настройки ширины коридора.
Для «от X» покрытие той же модели на тех же фолдах выросло с 23,4%
до 50,7% без изменения P50. Нижняя и верхняя границы в выходе
калиброванной модели — скорректированные границы номинального 50% коридора.
Выбор вариантов и проверка выполнены на одном снимке, отдельной
проверки на новых данных не было. Два оценённых среза вместе составляют
590 из 7 310 вахтовых вакансий (8,1%).

### Дополнительная проверка TF-IDF

Символьный TF-IDF (3–5 символов) и SVD на 32 компоненты обучались
внутри каждого обучающего фолда. Вход — заголовок, описание и льготы.
Перед векторизацией из текста удалены зарплатные фрагменты и цифры.

| Срез | Вариант | MAPE | Покрытие |
|---|---|---:|---:|
| Точная ставка / вилка | Карточка + TF-IDF | 21,4% | 28,0% |
| Точная ставка / вилка | Карточка + Костя, вахта, M4 + TF-IDF | 22,0% | 29,0% |
| «От X» | Карточка + TF-IDF | 24,7% | 27,2% |
| «От X» | Карточка + Костя, вахта, M4 + TF-IDF | 24,9% | 25,5% |
| «От X» | Карточка + TF-IDF с отдельной калибровкой | 28,0% | 46,6% |

На «от X» TF-IDF снизил MAPE модели по карточке на 3,7 п.п.
(парный бутстрэп по группам источников, 95% интервал от −7,4 до −0,04 п.п.).
При выделении групп под калибровку преимущество исчезло. Из двух
калиброванных вариантов результат без TF-IDF ближе к целевому покрытию 50%.

## Запуск

Из корня репозитория, с Python 3.12 и проверенным
`Data/dataset/vacancies.csv`:

```powershell
python -m pip install -r ML/experiments/2026-11-25_vahta_model/requirements.txt
python -X utf8 ML/experiments/2026-11-25_vahta_model/train.py
python -X utf8 ML/experiments/2026-11-25_vahta_model/calibrate.py
python -X utf8 ML/experiments/2026-11-25_vahta_model/tfidf.py
python -X utf8 ML/experiments/2026-11-25_vahta_model/tfidf.py --calibrate
```

Материализация общего датасета описана в `Data/dataset/README.md`.
На Windows проверка хешей частей требует исходных байтов Git без
преобразования LF в CRLF. Параметр `--data` принимает путь к проверенному
снимку, `--out` — папку результатов, `--without-nlp` отключает NLP-вариант.

Выходы: `dataset.json` — происхождение данных и причины исключения,
`target_quotes.csv` — единицы, формы и источники ставок,
`metrics.csv` и `predictions_oof.csv` — метрики и прогнозы на отложенных
фолдах, `*.cbm` — веса, `feature_schema.json` — порядок признаков.
Для прогноза на CSV с условиями вахтовых вакансий можно передать явно
выбранный файл весов через `predict.py <input.csv> <output.csv> --model <file.cbm>`.
Калиброванные веса требуют одноимённый файл `*.calibration.json` рядом
с моделью. Результаты калибровки — в `metrics_calibrated.csv` и
`predictions_calibrated_oof.csv`.
Для TF-IDF рядом с весами нужен также `*.encoder.joblib`.
