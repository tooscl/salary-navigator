# Почасовые пакеты для ставок за смену

Все сохранённые пакеты обучены на первом фолде. Они прогнозируют P25/P50/P75
опубликованной суммы в рублях за час на руки при заданной нагрузке. В пакетах
используется цель, полученная прямым делением сменной суммы на часы.

- Префикс exact — одно точное число часов.
- Префикс single_range — точные часы и середина одного закрытого диапазона.
- Файлы route содержат общий CatBoost, доступные модели режимов и ячеек и
  эмпирические квартили. Имя и область применения локального пакета записаны
  в [таблице опоры](../../experiments/2026-11-18_salary_hourly/specialist_support.csv).
- Файлы gold содержат квантильный Gradient Boosting ChewbyIrinine,
  структурированный CatBoost и CatBoost с очищенным TF-IDF по линии SSRtatarin.

## Применение

[Ноутбук](../../06_salary_hourly.ipynb) загружает сохранённые пакеты и показывает
результат на примерах. Установите [зависимости](../2026-11-18_priority_salary_gold/requirements.txt)
и запустите из корня проекта.

~~~python
import sys
import pandas as pd

sys.path.insert(0, "ML")
from run_salary_hourly import predict_hourly

vacancies = pd.read_csv("ML/experiments/2026-11-18_salary_routing/example_vacancies.csv",
                        dtype=str, keep_default_na=False)
result = predict_hourly(vacancies, hours_policy="single_range")
~~~

Передайте mode (ordinary, watch, remote), unit (shift), tax (net) и поле
«Количество рабочих часов в день». Остальные параметры карточки используются
при наличии. Контекст сопоставляется с областью поддержки пакета. Метод также
принимает карту правил формата предыдущего исследования. Имена подходов
соответствуют частям имён файлов после префикса exact_route_ или single_range_route_.
По умолчанию используется общий CatBoost с резервом на квартили внутри режима.

Выход содержит исходную единицу, выбранные часы и их статус, подход,
почасовые квантили и причину отказа. При сценарии пользователь видит,
что в расчёт взята середина диапазона. Проверяйте предполагаемую единицу
на вахте. Для объявлений с исходно почасовой ставкой был отдельный
эксперимент с расширением обучающего пула. Эти объявления не являются
входом сохранённой сменной схемы.
