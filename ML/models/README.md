# Обученные модели

Командные пакеты лежат в `<experiment_id>/`. Пакет `joblib` включает модель,
обработку признаков и калибровку, если она применялась. Паспорт прогона содержит
SHA-256 пакетов, версию данных, ID выборок, зависимости и метрики. Перейдите к
нужному ID в [таблице экспериментов](../experiments/README.md).

Чтобы проверить пакет маршрутизации без переобучения, укажите путь к паспорту в
`WEIGHTS_FROM` в [ноутбуке](../05_salary_routing.ipynb). Используйте пакеты из
доверенного источника. Перед добавлением новых пакетов проверяйте размер файлов.
