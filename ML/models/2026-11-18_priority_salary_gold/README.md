# Применение моделей приоритетных сегментов

В каталоге пять проверенных пакетов с обработкой. Все выдают P25/P50/P75
**в рублях за смену на руки**. Веса соответствуют обучению первого разбиения
и пригодны для воспроизведения и исследования. В сводке качество рассчитано
по прогнозам из трёх разбиений. Назначение модели ячейке требует отдельного решения.

| Пакет | Обработка и модель |
| --- | --- |
| [empirical.joblib](empirical.joblib) | Статистические квартили по городу и профессии. При слабой опоре используется профессия, затем совокупность за тот же период и на той же налоговой базе. |
| [chewby.joblib](chewby.joblib) | One-hot и три GradientBoostingRegressor с квантильной функцией потерь. |
| [cat_detail.joblib](cat_detail.joblib) | CatBoost MultiQuantile, параметры карточки, log1p суммы и поправки к квантилям по валидации. |
| [ssr_text.joblib](ssr_text.joblib) | Тот же CatBoost и 32-компонентное представление очищенного текста. Словарь и SVD входят в пакет. |
| [cat_relative.joblib](cat_relative.joblib) | CatBoost на отношении к медиане. В пакет входят медианы обучения и поправки к квантилям. |

Из корня проекта, PowerShell

~~~powershell
python -m pip install -r ML/models/2026-11-18_priority_salary_gold/requirements.txt
$dir = "ML/models/2026-11-18_priority_salary_gold"
python ML/predict_salary_gold.py --model "$dir/cat_detail.joblib" --input "$dir/example_input.csv" --output "$env:TEMP/avito_quantile_example.csv"
~~~

Поменяйте имя пакета, чтобы получить прогноз любого другого варианта на тех
же входных строках. Обязательные поля и типы перечислены в
[схеме входа](input_schema.json). Используйте значения city_resolved и
profession_resolved из канонической выгрузки. Сумма и форма вилки для
прогноза не требуются. Для модели с текстом можно передать заголовок,
описание и условия. Очистка выполняется внутри команды.
Загружайте joblib-файлы из доверенного источника.

### Обновление медианы без переобучения

Пакету cat_relative можно передать фрагмент проверенной канонической выгрузки
через --median-source, --median-from и --median-through. Используйте
новые наблюдения, собранные после обучающего окна и до даты прогноза.
Исключайте оцениваемые объявления и их дубли из файла обновления.
Точная медиана город × профессия меняется при 10 точках и 5 группах
работодателей в заданном окне. Существующая медиана и более общие уровни
используются при недостаточной опоре. Колонка anchor_level показывает
глубину резервного уровня, использованного для прогноза.

В исследовании хватило поздних данных на три независимые тестовые строки
с доступной новой медианой. На них медиана осталась прежней. Обновление
реализовано и воспроизводится, его влияние на точность ещё не установлено.
